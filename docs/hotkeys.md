# Common VSCode Hotkeys

## General
- `Ctrl+Shift+P` / `Cmd+Shift+P`: Command Palette
- `Ctrl+P` / `Cmd+P`: Quick Open File
- `Ctrl+,` / `Cmd+,`: User Settings
- `Ctrl+K Ctrl+S`: Keyboard Shortcuts

## Editing
- `Ctrl+X` / `Cmd+X`: Cut line
- `Ctrl+C` / `Cmd+C`: Copy line
- `Ctrl+V` / `Cmd+V`: Paste
- `Alt+↑/↓`: Move line up/down
- `Ctrl+Shift+K`: Delete line
- `Ctrl+Enter`: Insert line below
- `Ctrl+Shift+Enter`: Insert line above
- `Ctrl+/`: Toggle line comment
- `Alt+Shift+A`: Toggle block comment

## Navigation
- `Ctrl+G`: Go to line
- `Ctrl+Home`: Go to file start
- `Ctrl+End`: Go to file end
- `Ctrl+F`: Find
- `Ctrl+H`: Replace
- `F12`: Go to definition
- `Alt+F12`: Peek definition

## Window Management
- `Ctrl+B`: Toggle sidebar
- `Ctrl+\`: Split editor
- `Ctrl+W`: Close editor
- `Ctrl+Tab`: Switch between editors

## Multi-cursor and Selection
- `Alt+Click`: Insert cursor
- `Ctrl+Alt+↑/↓`: Add cursor above/below
- `Ctrl+D`: Select next occurrence
- `Ctrl+Shift+L`: Select all occurrences
- `Ctrl+A`: Select all

## Code Folding
- `Ctrl+Shift+[`: Fold region
- `Ctrl+Shift+]`: Unfold region
- `Ctrl+K Ctrl+0`: Fold all
- `Ctrl+K Ctrl+J`: Unfold all

Note: For Mac users, replace `Ctrl` with `Cmd` in most cases.
